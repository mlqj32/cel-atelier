# 模块首页宽屏留白修复（v32）

根因：main.css中的.layout和.topbar-inner有1640px居中上限；reader.css原先只给reading-page解除上限，module-page未被覆盖。2560px视口下原模块布局宽1640px、左偏移455px（页面滚动条占10px），目录起点483px。

修复：模块首页与章节页共享流式容器、响应式外边距和230–270px目录列，顶部导航同步对齐；小于等于1200px恢复单列与抽屉目录，560px以下保留模块页原有约20px总边距。reader.css资源版本升级到32。

修复后2560px视口下布局宽2550px、左偏移0，目录起点约61px。短说明文字仍有原有行长约束，卡片和章节列表可利用剩余屏幕。

验证：14个模块首页在320/390/768/1024/1200/1201/1440/1920/2560/3440px共140组检查，无整页横向溢出、所检元素越界或居中限宽残留；章节页另抽查390/1440/2560px，手机目录320px展开后边界0–310px正常。全站内容审计通过，已恢复默认视口。
