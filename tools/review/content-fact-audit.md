## 结论与范围

原稿确有知识错误、无依据的学习承诺，以及把示例参数写成通用规则的情况，已直接修订。范围覆盖13个模块、140章，以及章节补充、首页问答、图解和互动演示。20章主体重写，其余采用定点纠错并同步相关图解与测验。

“全量”在本记录中指全部章节及关联资源纳入遍历、渲染、引用和风险表述扫描；不代表每一句话都得到独立外部来源证明，也不代表每款软件、每个版本均已实机复现。官方资料核对与站内浏览器测试分别记录如下。

当前广度足以作为绘画入门与软件流程的学习地图；造型、赛璐璐主线有跟练、自测与完整案例。Live2D、职业和安全模块仍以入门与流程为主。阅读材料与静态审计不能保证零基础读者一定学会，是否掌握仍需看独立完成、迁移与纠错，尚无真实零基础学习者长期试学结果。

| 网格和描图 | 将网格辅助与描图等同 | 区分定位辅助、沿原图描线与其他使用方式，权利仍按素材许可判断 |
| 造型和光影 | 近远侧表述矛盾；三庭五眼、仰俯弧线、眼型性格等写得绝对 | 比例仅为概括；结合角度、个体和设计判断，性格联想不是解剖事实 |
| 赛璐璐 | 固定层数、单主光、固定高光色和阴影比例 | 基础方案可以简化，复杂方案也可成立；AO与二阴不同，高光受表面、光源与视点影响 |
| 图层剪贴 | 暗示上层阴影会随底色变动自动重新匹配 | 剪贴约束可见范围，不会自动重算颜色或位置 |
| 像素与色彩 | 混淆PPI/DPI、RGB/CMYK及指派与转换配置文件 | 区分像素尺寸与印刷尺寸；配置文件依用途、设备和印厂要求处理 |
| Apple Pencil | 泛化设备兼容与压感能力 | 按具体型号核对；USB-C款有倾斜感应、没有压力感应 |
| Procreate | 称不支持原生CMYK，或暗示可任意切换色彩模型 | 支持原生CMYK画布；同模型配置文件调整不等于可在RGB与CMYK之间任意切换；保留原生工程备份 |
| SAI2 | 漏掉Linework功能，把其他软件术语和菜单套入SAI2 | 补控制点/压力编辑；辅助尺与参数名称按实际构建核对，避免保证不存在的统一菜单路径 |
| CSP | 把PRO的24帧限制解释为24fps；填充、云与等级功能混淆 | 24帧是时间轴长度；闭缝与扩张分开；平台许可与云分开；联网自动上色涉及上传，需考虑保密 |
| Photoshop | 强制某一印刷配置、误解色调分离级别、保存或快照能力 | 配置按交付要求；色调分离按通道解释；无损保存不提高原有锐度，历史快照不替代长期备份 |
| Live2D | 工程/运行文件混淆、虚构PIE释义、将站内摆动当真实物理设置 | 区分工程与运行交付；删除虚构术语，明确站内示意与实际软件设置的区别 |
| 定金与授权 | 预付款一律称定金；买断含义唯一；商用倍数像行业标准 | 区分预付款与法律定金；中国大陆民法典第586条规定20%上限，超过部分不产生定金效力；授权逐项约定，倍数仅作演算 |
| 报价计算器 | 选择商用后复制文案仍写个人使用 | 预览和复制共用文案生成函数；金额、预付款及授权随选项同步，并列待确认范围 |
| 成本与加急 | 未达到目标时薪等同实际亏损，加急百分比像统一收费 | 目标收益与真实盈亏分开；加急比例明确是示例，应按项目协商 |
| 安全与内容边界 | 扫码一概等同设备失陷、改外观即可规避年龄疑义 | 按可观察迹象处理安全事件，疑似被控设备用干净设备改密；年龄疑义先暂停，伦理拒稿与各地法规分开 |
| 练习与复盘 | 时间差数学错误，自评像验证量表，“只改一个”像硬性规则 | 修正为4倍；自评仅供练习；可先控制变量，不把多处修改或休息一概归因于学习失败 |
| 网点图解 | 随机点数与透明度假装网点覆盖密度 | 使用确定的点覆盖率示意，避免视觉与说明不一致 |
