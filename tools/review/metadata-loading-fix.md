# 元数据工具加载失败修复（v31）

用户反馈的两个状态分别来自选图处理中的通用catch和教学样本fetch失败。原版直接按路径构造Worker并fetch教学PNG，存在直接打开HTML时受本地文件来源限制的兼容缺口；同步Worker启动异常也被错误归类成“文件未能读取”。不能仅凭截图确认用户实际URL或全部环境细节。

## 修复

- 将exifr、核心解析器和Worker消息处理器组合成随页面脚本载入的运行包，使用Blob Worker。Worker内部不再fetch/importScripts，不需要独立文件请求。
- 原创PNG样本以base64随运行包载入；实用检查器及第13章结构实验室均从相同内置字节读取。
- 选图使用FileReader，区分读取错误、解析组件缺失、Worker启动、解析错误、超时、展示错误。取消及切换图片释放线程、计时器与Blob URL。
- 新增可复现生成脚本；内容审计检查生成包与依赖、核心源码及样本的完整一致性，避免今后修改源码未更新离线运行包。

## 验证

- 9项新增运行回归全部通过：真实PNG/JPEG/WebP在禁用fetch/importScripts的VM中由完整打包解析器读取；样本与原文件逐字节相同；模拟启动阻止、异步错误、读取失败、超时、消息错误、取消、缺失运行包，确认错误分类与资源清理。
- 原有元数据15项、结构13项（合计37项）全部通过。14模块154章及42项内容事实回归审计通过。
- 浏览器实测教学样本、EXIF/XMP JPEG/WebP/PNG全部成功；用户提供的两张截图都成功读取尺寸及文件字节，本工具未提取到其中的软件或内部日期字段，正确呈现空状态。
- 第13章教学样本入口读取成功，SHA-256与原始PNG一致。
- 320/390/768/1440px下带长文件名、宽截图的检查结果无横向溢出，已恢复默认视口。记录见metadata-loading-fix.json；截图见metadata-loading-fixed.jpg。

浏览器自动化只允许HTTP/HTTPS，file://导航被URL策略阻止，因此没有声称完成真实浏览器文件直开实测。改用HTTP界面验收与禁用网络/导入的VM回归验证打包路径；不绕过浏览器访问策略。
