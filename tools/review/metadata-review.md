# 插画元数据检查器验收（2026-11-15）

实现位于 D:/代码项目/cel-atelier。逆向工程模块首页增加明显工具入口，第3章前部可选择/拖入 PNG、JPEG、WebP；第13章增加跳转说明。资源版本 v30。

## 能力与边界

- 本地 Worker 解析；图片字节不上传。exifr 7.1.3（MIT）保存在本地，保留许可与来源。
- 读取 PNG tEXt、iTXt（含压缩）、zTXt、tIME、eXIf；JPEG 标准 APP1 EXIF/XMP；WebP EXIF/XMP。分别保留块/段、标签组与字段值。
- 显示软件、日期、作者等选定字段，预览支持的位图；复制与下载 TXT 报告，支持清空和同一文件再次选择。
- 真实绘制起止、工时始终标为无法仅凭文件确定。lastModified 独立显示；不猜软件，不把日期当身份或过程认证。
- 最大32 MiB、解析超时12秒、单块元数据1 MiB、累计4 MiB、200个展示字段、单字段4000字符；预览上限4000万像素。声明超限或解析不完整。
- 不处理扩展XMP、私有MakerNote、GPS与完整ICC；同包重复属性不保证完整保留，不验证签名、整图解码或来源真实性。报告说明了范围。

## 验证

- 新解析测试15项通过：三种实际可解码图像、JPEG EXIF/XMP多工具、多时区、大小端与子视图偏移、PNG压缩中文、CRC错误、损坏偏移、压缩膨胀、长字符串、文件大小与字段数限制、无标签、未知SVG与非法日期。
- 原有结构实验13项回归通过；全站14模块154章、25交互工具/演示与42项内容事实回归审计无错误。
- 浏览器使用原创测试图片检查PNG/JPEG/WebP、无标签PNG、损坏PNG、含HTML字样的长文本、未知SVG、空文件和32 MiB超限文件。元数据中的HTML只作为文字显示，无注入图片。
- 复制按钮返回成功状态；实际下载TXT核对保留多个软件来源、原始日期、时区、lastModified及无法确定结论。
- 320/375/390/600/768/1024/1440px下检查结果、长字段展开报告和模块入口，另抽查四种宽度纸色主题；末轮修正标题被旧样式覆盖的问题并复验七种宽度，总32组检查未发现页面或工具横向溢出。
- 最终分组标题桌面19px、手机18px、上间距28px；操作按钮最小高度48px。恢复原阅读主题和默认视口。
- 浏览器未捕获警告或错误。详细记录：metadata-browser-audit.json；最终桌面图：metadata-desktop.jpg。

这些验证覆盖列出的格式与样本，不等于支持所有私有变体或证明元数据真实；未取得可靠阶段记录时，实际绘制时间仍然未知。
