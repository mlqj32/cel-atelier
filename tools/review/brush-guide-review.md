# 零基础路线与真实笔刷指南验收

核对日期：2026-11-15

## 学习顺序

原模块目录不宜直接当作顺序。现分为入门主线、软件上手、准备接稿、按目标选修。主线为：入门前夜 → 任选一款软件学基本操作 → 造型地基（同步练习）→ 赛璐璐小作品 → 接稿准备。练习从开始同步进行；Live2D、逆向工程按需选修。

桌面菜单与手机目录均提供学习路线、笔刷速查入口；修复非章节页面手机目录缺少实用导航的问题。

## 用笔内容

新增 assets/js/brush-guide.js，包含4款软件、7种任务，共28种方案；整理15个真实工具条目，提供中文名、原名、分类入口、用途、误用、步骤与验收。

Procreate：6B铅笔、工作室笔、单线、硬画笔、软画笔、水彩。SAI2：铅笔（部分汉化称通常笔）、水彩笔、喷枪。CSP：铅笔、G笔、水彩圆笔、柔软。Photoshop：硬边圆画笔、柔边圆画笔，并提供圆形笔尖与硬度参数定位。

来源链接和核对说明在页面及 brush-source-evidence.json 中。Procreate旧笔刷按5.4经典库说明；SAI2不存在统一官方中文名，以官方英文包原名核对。用途及参数为本站教学建议，来源核对工具存在性和功能，不声称官方指定某类稿件用笔。

同时纠正原课程中的CSP“6B”、SAI二值笔等于黑白且无压感、Procreate压力透明度设置等表述，并将具体练习用笔补入相关课程。
