# 元数据缺失时的候选推测

日期：2026-11-15

## 行为

- 先显示实际提取的声明；软件或日期缺失时，自动补候选推测。推测不加入 fields，不写回原图。
- 软件按文件名工具词、用途词和用户补充的用途/设备排序。例如“立绘”用途优先列出 CSP 与 SAI / SAI2；没有区分线索时保留并列。页面明确这是公开规则的排查顺序，没有经校准的统计概率，也不声称自动识别画风。
- 时间先核对文件名中的有效日历日期；否则以本地修改时刻提出带条件的候选。原始导出须满足画完即导出、时间未变等条件才可能接近完成；已标记下载/截图/转存时优先解释为获取或处理时刻，不再用于猜绘制完成。缺少一切日期锚点时说明可推测的处理过程，不编造具体日期或工时。
- 用户可手动补充用途、设备和文件来源，实时更新候选与报告。复制、TXT下载和报告预览包含相同的推测条件、依据和限制。
- 更新课程说明、缓存版本，并重建内置离线 Worker 运行包。
